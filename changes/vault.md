- **The Vault.** Settings › Vault keeps the secrets your agents use: provider API keys and environment variables. Values are encrypted on this computer with a key kept in the OS keychain, and are never shown again after you save them. Agent Rishi hides them wherever they would appear in transcripts. Grant a secret by role, project and end time to say where it may be used without asking. You can import the variables of a `.env` file in one go, and see every use, grant and change in the Vault's activity. If the keychain's key is missing or doesn't match, the Vault locks and changes nothing.
