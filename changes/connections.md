- **Connections with an API key.** Settings › Connections adds an account for Anthropic, OpenAI, Gemini, xAI or Sarvam AI with a key from the Vault, or a local OpenAI-compatible server such as Ollama, LM Studio or vLLM. Agent Rishi lists each connection's models from the provider itself, which costs no tokens, and marks it verified once that works. If a server doesn't list its models, you can add their IDs by hand. Sessions can't run on these connections yet; that comes next.
